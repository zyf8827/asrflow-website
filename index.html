产品简介

ASRFlow 是一个异构两阶段（2-Pass）实时语音识别网关。客户端通过单个 WebSocket 长连接持续推送 16kHz PCM 音频流并接收识别事件。网关将识别流水线划分为两遍：首遍（Pass-1）基于 ONNX Runtime 运行流式 Paraformer-online，输出 200~600ms 低延迟中间字（partial）并在 VAD 断句时产出快速整句（provisional）；二遍（Pass-2）在断句后异步调用独立部署的 Qwen3-ASR vLLM 服务，输出带标点的高精度定稿文本（final）。

在长时间流式会话中，流式模型常面临近零静音/底噪环境下的偶发孤立 Token 吐字、时间戳漂移以及下游重复拼接退化等问题。ASRFlow 通过分层退化防护（近零静音过滤、VAD 状态门控、超时看门狗及二遍一致性校验），在保持低延迟交互体验的同时，拦截异常字符积累。

服务采用解耦架构：网关自身不绑定重型推理框架，通过 HTTP 接口与独立部署的 vLLM 通信；首遍引擎支持多路并发动态合批，内置断线重连（resume 会话缓存）、动态热词偏置、说话人识别与逆文本正则化（ITN），并提供开箱即用的全 Mock 运行模式，本地无需 GPU 与模型权重即可调试全链路。

核心特性

①

异构 2-Pass 流水线

首遍 Paraformer-online（ONNX）提供 200~600ms 快速反馈（partial / provisional），二遍异步调用独立 Qwen3-ASR（vLLM）输出高精度标点定稿（final）。

②

首遍动态多路合批

流式引擎支持多路并发连接在动态时间窗口内组批推理，兼顾吞吐与低时延。

③

分层流式防退化

近零静音过滤、VAD 状态门控、超时看门狗与 Consistency Guard，拦截孤立 Token、时间戳漂移与幻觉积累。

④

架构完全解耦

二遍模型经 HTTP 调用独立 vLLM 进程，网关依赖轻量，vLLM 不进入服务依赖树。

⑤

会话管理与掉线恢复

基于 session_id 的断线重连与 resume 会话缓存；支持客户端 commit 信令强制切句。

⑥

Mock 调试开箱即用

全 Mock 引擎无需 GPU 与模型权重即可走通 WebSocket 推流与识别链路；另含热词、说话人识别、ITN 与健康探针。

快速开始

Python ≥ 3.10。无需下载模型权重即可体验完整 WebSocket 推流与识别链路：

# 克隆仓库
git clone https://github.com/zyf8827/asrflow.git
cd asrflow

# 安装最小基础依赖
pip install -r requirements-base.txt

# 启动全 Mock 网关
python3 main.py \
  --port 10095 \
  --http_port 10096 \
  --streaming_backend mock \
  --final_backend mock \
  --vad_backend mock \
  --speaker_backend mock

完整真实模型部署、Docker 编排与客户端协议说明见 GitHub README。
